# Ohvii

Buy a California home through the AI you already use. Research homes, compare sales and review disclosures, then prepare offers and counters. Generate purchase agreements, addenda and repair requests, and track deadlines with guidance through closing. You choose the terms, review documents, sign securely and approve delivery.

Ohvii supports self-represented buyers in California. A free Ohvii account is required. Ordinary third-party homebuying costs still apply.

## Connect

Install this plugin on a supported Claude surface. Connect the Ohvii MCP server
and sign in to your Ohvii account. Review the requested permissions on the OAuth
consent screen. Never put passwords, tokens, or signing codes into a chat.

The plugin declares one remote server: `https://ohvii.com/api/mcp`, using
Streamable HTTP and OAuth. It bundles one readable buyer-workflow skill. It does
not run a local server, install dependencies, execute hooks, or bundle scripts.
Supported surfaces and installation steps are described in the
[developer documentation](https://ohvii.com/developers).

## Try it

- “Show my saved homes, compare the available nearby sales, and explain what still needs verification.”
- “Help me prepare an offer for my saved home. Show the terms and unresolved choices before asking for my approval.”
- “Review my transaction documents and deadlines, explain the next buyer decision, and identify any missing information.”

Claude's available search and browser capabilities help with home discovery.
Ohvii supplies the buyer workspace, saved property research, document tools,
and transaction workflow. Features can differ across Claude surfaces; secure
web handoffs are available where the host cannot show an interactive card.

## Data and approvals

The connected Ohvii service reads and stores information needed for your buyer
workspace, including profile details, saved homes, transaction documents,
messages, and signing evidence. Authorized tools can update those records and
send buyer-approved transaction emails through Ohvii. Ohvii uses service
providers described in its [privacy policy](https://ohvii.com/privacy).
User-requested research may also use Claude's own available tools.

Consequential actions keep Ohvii's review, approval, signing, and delivery
requirements. A prepared draft is not a sent message or signed contract.
Ohvii does not move money. Research is not an appraisal or a guarantee about
a home. The [terms of service](https://ohvii.com/terms) describe service limits.

## Help

If a connection expires, reconnect through Claude and complete Ohvii sign-in.
If a write fails or its outcome is uncertain, check the saved workspace before
retrying. Do not repeat a send or signing action without checking its status.
You can manage or revoke access in your Ohvii account.

For help, use [Ohvii support](https://ohvii.com/support) or email
[info@ohvii.com](mailto:info@ohvii.com).
